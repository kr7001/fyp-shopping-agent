2. What the run can and cannot claim

One held-out market (a single product, a tee, with misleading size labels), one model (DeepSeek V4 Flash), four arms (the shipped agent, the shipped agent told to open everything, the block with rules, the block with a model reading the question), three rounds. It tests four hypotheses, corrected together by Holm's method:

Hypothesis
H1The block (model) is correct more often than the shipped agent, on seven questions whose answer has one reading.
H2The block opens fewer listings than open everything, on eight gated questions.
H3The block costs less per run than open everything, on the same questions.
H4On reworded questions the block was not built on, the model reading the question is correct more often than the rules.

It cannot show that the block works on other markets, other products, other models or another agent scaffold, or on live sites. It does not test search relevance, shipping cost or discounts after combination, which are out of scope as you asked.

4. Limitations and recorded conditions

  • One market, one product, one model; three rounds, so intervals will be wide.
  • The block's plan text was told the label kinds (promotional and stock text in a size menu); the other arms were not. Part of the gain on the label questions measures that sentence.
  • H3 compares the block's plan, briefing and page reading with an agent told only to open everything; it does not isolate the stop rule.
  • The second reader is an LLM verifier, not an independent person.
  • The shop's “Related search terms” block grew with each search, and the chain recorded it for every run. One search (“Wexcombe Midweight Jersey Tee”, 25 Oct 12:16) is in no agent log and was probably a human click. The last 22 batches ran after the 16-minute stop.
  • Two amendments were made during execution (the cap, the resume), both logged with their times; neither changes the design.

B. May the second reader be an LLM verifier, or must it be a person?

  • LLM (the protocol as frozen): available now, blind by construction, free. But it shares tooling and habits with the project, so agreement is weaker evidence of correct scoring.
  • Person: independent. But it needs a volunteer who learns the reading rules, about an hour for 40 rows.
  • Lean: keep the verifier, and add a person on the same 40 rows if one can be found; report both.
