The new rule, and what it costs

All five existing rules read something the answer says about itself, so an agent that says less about itself gets checked less. The new rule reads the question and the record instead, and needs the answer to volunteer nothing.

The principle. Naming the best item in a market is only supported by the evidence if the evidence rules out the rest of the market. The market generator already works out the fewest listings any correct method could open, after skipping everything the advertised prices allow it to skip. For these markets that is 11 of 15. Below that, an answer can still be right, but it was not worked out, it was landed on.

It also refuses four answers my own method got right. Those four opened nine listings of fifteen, below the eleven that any sound method needs, so the method is skipping more than its own reasoning justifies and got away with it on these draws. Under the new rule my method reads 7 right, 5 refused, 0 wrong instead of 11 right, 1 refused, 0 wrong. I am reporting both rather than quietly restating the first one, because the twelve runs were scored under the older rules and that is what they measured.

Magento writes the size surcharge into the dropdown label, and ships every size's price inside the page's own JavaScript. So inside a listing the agent can add rather than click, and 48 of 290 stored answers show it doing exactly that, for example "base price $5.54 plus pack size upgrade $14.21". The wall that really holds in this shop is the one between the search page and the listings, which is where every failure I have measured actually happens. The wall inside a listing is real on the live marketplace and weaker here, and that is now written down as a limit of the environment rather than left implied.

6. What I built this week

All of it free to run, and none of it changes anything the agent can see, which is what lets the runs already recorded stand.

THE HONEST LIMIT

Twelve runs is a direction, not an interval

Three attempts per question. Enough to see a difference this size, not enough to put a confidence interval on it. The budget buys breadth or depth and I have chosen breadth, on the grounds that one more market changes the story more than three more repeats would.
