Retrieval Policies
for Shopping Agents

Deciding what a shopping agent needs to open before it answers.

A listing's advertised price may belong to a different size from the one the shopper wants. This project studies information that becomes visible only after interaction, and builds a question-aware retrieval block for openJiuwen on a self-hosted WebArena-Verified shop.

The method

The block reads the question and result pages, chooses whether to clarify, decline or plan, and supplies the browser agent with a retrieval strategy. For suitable price queries, valid advertised lower bounds let it skip listings that cannot improve the answer. That stopping rule is conditional; it does not guarantee that a language model interprets or executes perfectly.

The evaluation

Seeded markets make prices and availability auditable. Comparisons use the shipped agent, an open-everything instruction, and rules/model versions of the block. Protocols are fixed before the claim-market draw, and answers are scored under written rules.

Evidence status · 27 October 2026
The second experiment has finished execution; blind human scoring is in progress. Final accuracy conclusions remain pending.

The second experiment includes deliberately misleading labels and selects markets with useful bounds. Only the block receives a warning about those labels. Results therefore concern a constrained stress test and the whole intervention; prompt-injection defences were not evaluated.
